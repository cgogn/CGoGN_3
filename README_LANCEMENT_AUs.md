Afin de lancer le programme pour les AUs et les envois à Openface 
Utiliser cette commande depuis ./build/stage/bin/

./action_unit_switch AUs/{dossier contenant les AUs soient avec le corps soient uniquement le buste} {texture dans le dossier textures}

Exemple

./action_unit_switch AUs/buste_no_brows_clean/ f001_head_color.tga

Le programme va créer un nouveau csv pour faire les calculs de matrice jacobienne et prendre un peu de temps afin de faire tout les calculs et les envois à OpenFace
